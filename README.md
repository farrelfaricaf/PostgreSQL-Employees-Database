# 📝PostgreSQL Employees Database

## 📑Database Project: employees.sql

This project is an individual assignment for the **Database Programming** course. The objective is to document the installation steps for PostgreSQL and Navicat, as well as to load the schema and data from the `employees.sql` database.

## 📜Background

This project uses the `employees.sql` dataset, which was originally designed for MySQL. Given that this assignment requires the use of **PostgreSQL**, the original script could not be executed directly due to syntax differences. To overcome this challenge, the script's code was converted to be compatible with PostgreSQL. This conversion was performed with the assistance of **Artificial Intelligence (AI)** to ensure accuracy and efficiency.

The original repository can be accessed [here](https://github.com/datacharmer/test_db).

## 📁Repository Structure

* `employees_postgres.sql`: The converted SQL script to create a PostgreSQL-compatible table schema.
* `README.md`: This document.
* `.dump` Data Files: Several data files from the original repository have been uploaded here. However, very large data files (like `load_salaries.dump`) could not be uploaded directly to GitHub. You can download them via this link:
    [File .dump](https://drive.google.com/drive/folders/1ESnLRchBTF9cUKWERje_sRLfl1RgrNbr?usp=sharing)
